# ReviewPulse Dashboard

## 🎯 Overview

ReviewPulse is a premium SaaS-style dashboard built with React + Vite that helps e-commerce brand owners aggregate, analyze, and act on thousands of customer reviews across multiple platforms including Amazon, Flipkart, Myntra, Ajio, Google Reviews, and Social Media.

The dashboard focuses on actionable insights through analytics, sentiment tracking, AI-generated recommendations, competitor benchmarking, and review management.

---

## ✨ Features

* KPI Summary Cards
* Sentiment Analysis Dashboard
* AI Insights Panel
* Keyword Analysis
* Competitor Benchmarking
* Review Management Table
* Alerts & Notifications
* Dark / Light Theme
* Responsive SaaS UI

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/MonishNarainN/ReviewPulse.git

cd ReviewPulse
```

### Install Dependencies

```bash
npm install
```

### Run the Development Server

```bash
npm run dev
```

Open:

```text
http://localhost:5173
```
